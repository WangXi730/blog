# 静态网站
## 定义
静态网站是由一组预先制作好的、内容固定的HTML、CSS和JavaScript文件组成的网站。当用户访问时，服务器会原封不动地将这些文件发送给用户的浏览器，浏览器再解析并呈现出来。
## 特点
- 内容固定：网页内容在发布之前就已经确定，除非开发者手动修改源代码并重新上传，否则内容不会自动变化。

- 加载速度快：因为服务器不需要处理复杂的逻辑或查询数据库，只是简单地传送文件，所以通常加载速度非常快。

- 安全性高：没有数据库、没有复杂的服务器端程序（如PHP、Python），黑客可以攻击的“入口”非常少，因此相对更安全。

- 成本低廉且易于部署：托管静态网站的服务（如GitHub Pages）很多都是免费的，或者非常便宜。部署也极其简单，只需把文件拖拽到服务器即可。

- 可扩展性强：在面对高流量时，静态文件很容易通过CDN（内容分发网络）进行全球缓存，轻松应对访问高峰。
